# 断线重连按 VID/PID 匹配端口

WSL usbipd 场景下 USB 串口意外拔出再插回时，内核可能给设备分配不同设备名（`ttyUSB0` → `ttyUSB1`），仅按端口名重连会永久失败。自动重连采用两级匹配：原名优先；原名消失时按连接时记录的 USB VID/PID 在当前可用端口中匹配。

## Consequences

- VID/PID 不能唯一标识物理设备，原端口名也可能被其他设备复用，因此不保证重连到原设备。本决策优先恢复连接，接受该边界；需要严格设备身份时应手动确认。
- 非 USB 串口（无 VID/PID）只按原名重连；原名未恢复则重试耗尽后提示手动重连。
